Документация / руководство

Начало работы

Три шага до первого сообщения: профиль, собеседник, переписка.

Что понадобится

Shum у вас и у собеседника. Для переписки рядом включите Bluetooth, для переписки на расстоянии нужен интернет.

1. Создайте профиль

При первом запуске придумайте имя и выберите аватар. В этот момент на устройстве создаются ключи профиля. Имя видят собеседники, а Shum ID отличает вас от всех остальных.

Алексей

Личный профиль, ключи на устройстве

Shum ID: 6f8c…2a91

2. Добавьте контакт

Покажите свой QR-код, отправьте ссылку или найдите человека рядом. Переписка начнётся, когда он примет приглашение.

3. Отправьте сообщение

Рядом сообщения идут по Bluetooth, на расстоянии через релеи Nostr. Статус в чате подскажет, какой путь сейчас доступен.

Bluetooth и релеи

У Shum два пути доставки, и выбирать между ними вручную не нужно.

Bluetooth работает, когда собеседник рядом, обычно в пределах нескольких десятков метров. Сообщение идёт напрямую, интернет не нужен, а другие устройства с Shum поблизости могут передать его дальше по цепочке.

Релеи Nostr работают через интернет на любом расстоянии. Это открытые серверы, которые хранят и пересылают зашифрованные конверты, но прочитать их не могут.

Shum сам выбирает доступный путь, а статус в чате показывает, какой сейчас работает.

Shum в терминале

Кроме приложений, у Shum есть CLI: версия для терминала, то есть для командной строки. На Mac это приложение «Терминал».

Сначала установите CLI, как описано в разделе «Загрузки», блок CLI. Затем откройте терминал и выполните команды по порядку:

  • shum init создаст профиль: имя и аватар,
  • shum откроет полноэкранный интерфейс с чатами,
  • shum chats покажет список чатов прямо в командной строке.
Terminal
# установить (macOS)
brew install hitechteam/shum/shum
# создать профиль
shum init
# открыть чаты
shum
Несколько устройств одного профиля

Сейчас профиль работает на одном устройстве. В первой стабильной версии протокола один профиль можно будет привязать ко всем своим устройствам по QR-коду, в любую сторону: с телефона на компьютер и обратно.
