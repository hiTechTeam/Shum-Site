CLI

Shum для тех, кто живёт в терминале: команды и полноэкранный интерфейс. Превью 0.1.7 для macOS 15 и новее, Apple Silicon и Intel.

macOS

Homebrew

brew install hitechteam/shum/shum

macOS 15 и новее, Apple Silicon и Intel. Обновление командой brew upgrade.

macOS

curl

curl -fsSL https://raw.githubusercontent.com/hiTechTeam/Shum-CLI/main/install.sh | sh

Без Homebrew и без sudo. Скачивает выпуск из GitHub Releases и сверяет SHA-256. Посмотреть скрипт ↗
