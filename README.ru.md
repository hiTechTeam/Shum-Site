# Shum Site

[English](README.md) · Русский

Информационный сайт Shum с загрузками. Next.js со статической выгрузкой, русский и английский языки, светлая и тёмная темы.

## Запуск

```sh
npm ci
npm run dev
npm run build
```

Разработка: `http://localhost:3100`. Готовый сайт: `out/`, для статического хостинга. Сервер приложения не нужен.

Опубликован на [getshum.tech](https://getshum.tech) через GitHub Pages из ветки `gh-pages`. Чтобы выложить последний коммит, выполните `npm run deploy`: команда собирает сайт локально и отправляет `out/` в эту ветку.

## Структура

- `app/(ru)` и `app/en`: русский в корне, английский под `/en/`.
- `components/pages/`: обзор, загрузки, документация, протокол и безопасность.
- `lib/i18n.ts`: тексты на двух языках.
- `components/` и `app/globals.css`: общие элементы, пиксельная графика и темы.

Дизайн основан на странице Figma «Сайт · Shum». Шрифты раздаются локально через Fontsource по OFL. Аналитики и сторонних скриптов нет. Выбор темы, копирование команд и мобильная навигация используют клиентский JavaScript.
